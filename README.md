# 2026 환경위기시계 — AI 리더십 과정 2기 실시간 설문

환경재단 × 매일경제 공동기획 **AI 리더십 과정 2기** 원우 대상, 2026 환경위기시계 실시간 설문·대시보드 웹페이지입니다.

- 원우가 스마트폰으로 설문에 응답하면(환경문제 3가지 선택·순위·위기시각, 해결 요인 선택) 즉시 저장되고,
- 같은 페이지 하단 대시보드에 실시간(약 5초 간격)으로 반영되며,
- 어제 환경재단·아사히글라스재단이 발표한 **2026 세계/한국 환경위기시계(9:39 / 9:34)** 와 나란히 비교됩니다.

## 폴더 구조

```
index.html          메인 페이지 (설문 + 실시간 대시보드, 순수 HTML/CSS/JS)
config.js            백엔드(Apps Script) 주소 설정 파일 — 배포 후 이 파일 한 줄만 수정
assets/               공식 환경위기시계 이미지 · 추이 인포그래픽
apps-script/Code.gs   Google Sheets 기반 실시간 저장소 백엔드 코드
```

## 1. 실시간 저장소(백엔드) 설정 — 최초 1회, 5분 소요

참가자는 로그인 없이 링크만으로 참여해야 하므로, Google 스프레드시트를 무료 실시간 DB로 사용합니다.

1. Google 드라이브에서 새 **Google 스프레드시트**를 만듭니다. (이름 예: `2026 환경위기시계 응답`)
2. 상단 메뉴 **확장 프로그램 → Apps Script** 클릭.
3. 기본으로 열려 있는 `Code.gs`의 내용을 모두 지우고, 이 저장소의 [`apps-script/Code.gs`](apps-script/Code.gs) 내용 전체를 붙여넣습니다.
4. 저장(Ctrl+S) 후 우측 상단 **배포 → 새 배포**.
5. 유형에서 **웹 앱**을 선택합니다.
   - 실행 계정: **나(Me)**
   - 액세스 권한: **전체(Anyone)**
6. 배포를 누르면 나오는 웹 앱 URL (`https://script.google.com/macros/s/.../exec`)을 복사합니다.
7. 이 저장소의 [`config.js`](config.js) 파일을 열어 `SCRIPT_URL` 값을 방금 복사한 주소로 바꾸고 저장합니다.
8. 변경사항을 커밋·푸시하면 실제 사이트에 반영됩니다.

> 참고: 스프레드시트에는 `Responses` 시트가 최초 응답 시 자동 생성됩니다. 응답 원본 데이터를 직접 확인하거나 백업하고 싶을 때 이 시트를 열어보면 됩니다.

## 2. 웹페이지 배포 (GitHub Pages)

1. 이 저장소를 GitHub에 푸시합니다 (이미 `helena0929/2026_test` 저장소에 연결되어 있습니다).
2. GitHub 저장소 페이지에서 **Settings → Pages** 로 이동합니다.
3. **Source**를 `Deploy from a branch`, 브랜치는 `main`, 폴더는 `/(root)`로 설정 후 저장합니다.
4. 1~2분 후 `https://helena0929.github.io/2026_test/` 주소로 접속되면 완료입니다.
5. 이 링크를 원우들에게 QR코드나 문자로 공유하면 됩니다.

## 3. 설문 방식 (환경재단 공식 방법론과 동일)

1. **위기 인식 (환경위기시계)**: 9개 환경 이슈 중 가장 시급한 3가지를 선택 순서(=중요도 순위)대로 고르고, 각 이슈마다 시계 다이얼(0:10~12:00, 10분 단위)로 위기 수준을 표시합니다.
2. 개인 위기시각 = `1순위 시각 × 0.5 + 2순위 시각 × 0.3 + 3순위 시각 × 0.2` (환경재단 설문지 예시와 동일한 가중 평균 방식).
3. **해결 요인**: 글로벌 환경문제 해결에 가장 중요한 요인을 11개 중 최대 3개 선택 (기타 의견 자유 기술 가능).
4. 대시보드의 "원우 평균 위기시각"은 전체 응답자 개인 위기시각의 산술 평균입니다.

## 4. 커스터마이징

- 색상·폰트 등 디자인 토큰은 `index.html` 상단 `<style>` 의 `:root` 변수에서 조정할 수 있습니다.
- 설문 문항(이슈 9개, 해결 요인 11개)은 `index.html`의 `ISSUES`, `SOLUTIONS` 배열에서 수정합니다.
- 공식 발표 수치(세계 9:39 / 한국 9:34)는 `WORLD_MIN`, `KOREA_MIN` 상수에서 관리합니다.
